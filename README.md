# 欧阳雨晴 2026 视觉设计作品集

个人视觉设计作品集网站，包含 108 页作品展示、目录章节导航、项目内导航、视频和卡片交互。

## 本地查看

直接打开 `index.html` 即可浏览完整作品集。

## 网站结构

- `index.html`：网站入口
- `script.js`：页面生成、章节导航和交互
- `pages/`：作品集页面图片
- `assets/`：目录与项目素材
- `cards/`：个人作品卡片素材
- `media/`：项目视频
- `*.css`：页面布局、动效和视觉样式

## 部署

这是一个静态网站，可以部署到 GitHub Pages、Cloudflare Pages、Netlify 或其他静态网站托管服务。
